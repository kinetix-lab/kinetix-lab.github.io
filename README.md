# Kinetix Labs website

Static site for [kinetixlab.co.uk](https://kinetixlab.co.uk), served by GitHub Pages from the `main` branch.

Kinetix Labs is a trading name of Kinetic Goods Ltd.

## DNS

Point the domain at GitHub Pages:

- Apex `kinetixlab.co.uk`: `A` records to `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
- `www`: `CNAME` to `<github-user>.github.io`

Then turn on **Enforce HTTPS** under Settings → Pages.
